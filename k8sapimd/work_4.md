## 댓글분류 모델과 input 서비스 기능
mlops 실습가이드 1부 html을 읽어 보면 댓글분류모델과 그 모델을 활용해 댓글을 인풋하면 결과를 반환하는 app.py 가 보일 것이다.
이를 응용하여 본 프로젝트의 목표를 달성하고자한다. 
우선 모델을 어떤 식으로 배포해서 본 서버와 상호작용하게 하냐가 첫 문제이다.
1. 한꺼번에 하나의 파드 하나의 컨테이너로 만다.
2. 사이드카 컨테이너 패턴으로 간다.
3. 별도의 2개의 파드로 배포한다.

이중에서 현재 고려중인 방안은 2번이다. 2번으로 진행될 시 app.py 에 해당하는 앱 서버는 server 디렉터리안에 코드를 작성, model만 model이라는 별도 디렉터리로 작성하고자한다. 

요구되는 기능은 메뉴바 댓글기능에서 댓글을 직접 작성하여 input하면 모델이 이를 받아 추론을 하고 결과를 페이지에 반환하는 간단한 서비스이다. work_4 이후 work_5에서는 여기서 DB와 연동하여 결과를 페이지에 반환하면 DB에 트랜잭션을 수행할 예정이다.
