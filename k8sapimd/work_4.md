## 댓글 분류 모델 및 입력 서비스 구현

MLOps 실습 가이드 1부 HTML을 살펴보면 댓글의 유해성을 분류하는 머신러닝 모델과, 사용자가 댓글을 입력하면 모델이 이를 추론하여 결과를 반환하는 app.py가 구현되어 있다.

본 프로젝트에서는 해당 실습 내용을 응용하여 사용자가 웹 서비스의 댓글 메뉴에서 직접 댓글을 입력하고, 모델의 추론 결과를 화면에서 확인할 수 있는 기능을 구현하고자 한다.

이를 위해 먼저 기존 플랫폼 서버와 댓글 분류 모델을 어떤 구조로 분리하고 연동할 것인지에 대한 설계가 필요하다.

현재 고려하고 있는 배포 방식은 다음 세 가지이다.

하나의 Pod에 하나의 컨테이너로 구성하여 애플리케이션과 모델을 함께 실행하는 방식

하나의 Pod에 여러 컨테이너를 배치하는 사이드카 패턴

애플리케이션 서버와 모델 서버를 각각 별도의 Pod로 분리하는 방식

각 방식의 장단점을 비교하고, 프로젝트의 기존 서버 구조와 Kubernetes 운영 관점에서 가장 적합한 방식을 제안해 달라.

또한 코드 구조는 애플리케이션 서버를 server/ 디렉터리에, 모델 학습 및 추론 관련 코드를 model/ 디렉터리에 분리하는 방향을 고려하고 있다.

구현할 기능의 기본 흐름은 다음과 같다.

사용자가 좌측 메뉴의 댓글 기능에 접근한다.

댓글 입력창에 텍스트를 작성하고 분류를 요청한다.

애플리케이션 서버가 모델 서버에 추론을 요청한다.

모델 서버는 입력된 댓글을 분석하고 분류 확률을 반환한다.

애플리케이션 서버는 추론 결과를 가공하여 사용자 화면에 반환한다.

이번 작업(Work 4)의 범위는 댓글 입력부터 모델 추론 결과를 화면에 표시하는 것까지이다.

이후 Work 5에서는 해당 기능을 DB와 연동하여 추론 결과를 저장하고, 결과에 따른 DB 트랜잭션을 수행할 수 있도록 확장할 예정이다.

위 요구사항을 바탕으로 다음 사항을 중심으로 구현 계획을 수립해 달라.

기존 플랫폼 서버와 모델 서버 간의 적절한 아키텍처 설계

모델 학습 및 추론 서버의 코드 구성과 역할 분리

애플리케이션 서버에서 모델 서버를 호출하는 API 설계

댓글 입력 및 추론 결과를 표시하는 프론트엔드 구성

향후 DB 연동과 모델 운영 확장을 고려한 설계 방향
