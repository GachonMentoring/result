## 모델 재학습 자동화 파이프라인 관련

다음에 수행할 것은 가동중인 모델의 재학습을 위한 job 파이프라인이다.
현재 메뉴바에서 모델 재학습 관련 항목을 추가하고 모델 재학습을 클릭하면 또 3개의 메뉴 중 하나를 고를 수 잇다
데이터셋 재생성 -> DB의 데이터를 csv로 뽑아내서 NFS에 저장한다.
모델 재학습 -> csv를 선택해서 모델을 재학습하고 재학습된 모델을 저장한다.
모델 교체 -> 원하는 모델을 골라서 모델을 교체한다.

이것이 수행하고 싶은 기능이며, 여기서 고려해야할 부분은 첫번째 본 프로젝트의 댓글분류 모델이 cpu 만 있는 본 서버에서도 학습이 가능한 수준인가? 혹은 AWS 인프라를 통한 학습 이 필요한가?

두번째 NFS에 모델을 여러개 저장하고 원하는 때 교체할수 있을 정도로 모델의 용량의 충분히 작은가?
