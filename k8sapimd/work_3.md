# 세번째 매니페스트 관리 기능에 대하여

본 매니페스트는 선언형 관리: 쓰기 + 판정 을 담당한다. 
본 작업 단계는 헷갈릴 가능성이 다분하고, 한번 엉키기 시작하면 복구하기 힘드니 신중한 판단이 요구된다.

좌측 탭에 새로운 매니페스트 관리 라는 항목이 생길 것이다.
그리고 해당 항목을 통해서는그 항목 옆에 또 하나의 메뉴바가 생기게 될 것인데 그것은 NFS 서버의 특정 경로에 있는 manifest를 임포트해오는 것이다. 즉 NFS의 /home/suhan/manifests (실제로 위 폴더 사용) 안의 모든 yaml 확장자를 조작하려는 것이다.
해당 지점에서 오해하면 안되는 것이 Claude가 처음에 NFS를 pv/pvc로 마운트하자는 제안이 왔었다. 여기서 실제로 nfs 디렉터리에 외부에서 직접 파일을 추가할 상황이 자주 있을 것이라는 걸 인지하고 nfs 디렉터리내에서 직접 수정한 것이 pod에 바로 반영되는지 한번 체크 할 필요가 있다. 

구현하고자 하는 기능은 즉, 해당 경로 내의 yaml을 선택 이후 코드의 수정/삭제/저장/apply까지의 기능을 수행하고자 하는 것이다.

해당 매니페스트는 백엔드 즉 python api 서버 구현까지만을 담당하도록한다.
